## 🚀 How to Submit These Deliverables

### A. Academic Report Submission
- Submit [`SkillUp_Academic_Project_Report.docx`](./SkillUp_Academic_Project_Report.docx) directly to your university portal or print it for spiral/hardbound binding.

### B. Figma Design Submission
1. Open [Figma](https://www.figma.com) and create a **New Design File**.
2. Drag the 3 SVG files from [`figma_assets/`](./figma_assets/) into the canvas. Figma automatically turns them into editable vector frames.
3. Drag [`figma_showcase.jpg`](./figma_showcase.jpg) onto the canvas as the cover artboard.
4. Export the `.fig` file: **Figma Menu (top-left) ➔ File ➔ Save local copy...**
5. Get the share link: **Share (top-right) ➔ Anyone with link can view ➔ Copy link**.

### C. Single-File Submission (ZIP Archive)
- A single bundled zip archive is available at:  
  **`SkillUp_Academic_Deliverables.zip`** (located at the root of the repository).
- This archive contains all of the above non-code deliverables in one package for instant email or LMS upload.
